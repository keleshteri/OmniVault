# OmniVault

> An opinionated Obsidian vault template — structured, extensible, and ready to use.

## Use this template

1. Click **"Use this template"** → **"Create a new repository"**
2. Clone your new repo and open the folder as an Obsidian vault
3. Customize to your workflow

## What's included

- Folder structure for notes, projects, resources, and archives
- Pre-configured `.gitignore` so workspace state stays local
- Ready to extend with your own plugins, themes, and settings
